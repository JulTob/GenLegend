# 📜 Decrees — the settled law of the Agora

A **Decree** is a decision **ratified by Julio**. Once recorded here, it is binding on all agents and readable by all — this folder is the project's long-term memory of *what was decided and why*.

## Rules
- An agent may **draft** a Decree from a converged Dialog; only **Julio ratifies** it (see `Canon/Single-Source-of-Truth.md`).
- One Decree per file: `NNNN-short-slug.md`, numbered to match its Dialog where possible.
- A Decree records the decision **and the reasoning** — including the alternatives not chosen, so future readers understand the tradeoff.
- A Decree that changes Canon must reference the exact Canon edit Julio made.

## 🔍 Diagnosis (what & where)

`requirements.txt` pins `topkit==0.2.0a3` (2026-09-06, on PyPI 2026-09-21). Upstream released **0.2.0a4 on 2026-10-02**, on PyPI, through Trusted Publishing. It is the release the standing rulings were waiting for:

- **A Flag's words** (STEP-SPEC-17): `@Flag( "Martial Arts" )`. The 3b ruling keyed lasting effects by class name because words did not exist.
- **A late Flag takes the `in` seat**: closes QST-0093.10 §1; the "Role first" ordering in `CharactersKit` stays right but its explanatory comment is now history.
- **Field algebra** (STEP-SPEC-13) and **condition members** (STEP-SPEC-14), which QST-0093.11 listed as "0.2.0a4 (unreleased)" and planned to adopt "when published".
- Three memory leaks fixed; memory per Character down 19 to 34 per cent; keyword and Field reads 53 to 75 per cent faster.

Two facts change the project's own documents:

1. **Python 3.12 or later is required** (`pyproject.toml`). The container (`python:3.14-slim`) and CI (3.14) already comply. `requirements.txt` still says "Python 3.10+", and the Makefile still accepts 3.10 and 3.11 when it looks for an interpreter.
2. **A new refusal.** A condition may not share its name with a Record, an Action, a host member or a value the Agent already holds (STEP-SPEC-14 §4). None fired in the dry run; the wide grid decides.

## 🛠️ What landed (2026-10-05, PR #102)

- `requirements.txt`: `topkit==0.2.0a4`, the comment rewritten; the Python floor is 3.12 here, in the Makefile's interpreter search (3.11 and 3.10 dropped) and in the README.
- `CharactersKit.Role`: the docstring no longer explains the fixed late-Flag defect; the Role-first order stays as design.

- `SpellsKit`: the 0.1 name probe is retired (only a Flag answers `in`, exactly) and `Label()` becomes `NAME`. Repairing the test exposed a real gap: a second School was **not refused**, because `Single_School` sat on the `School` root and TopKit 0.2 runs a gate only for the Tags the call applies. The rule now sits where the tagging happens, as Julio ruled: each of the 8 Schools declares `Only_One_School` and each of the 10 Levels `Only_One_Level`, through `No_School_Yet` and `No_Level_Yet` beside their roots. All 566 spells in the Lodge still carry one school and one level.

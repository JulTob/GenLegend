## 🔍 Diagnosis (what & where)

Since TopKit 0.2.0a2 a Report is declared by a builder (`@Report def X( tag )`), and `Report( value )` is refused. The factories that make Tags from data rows (`Make_Training`, `Make_Guild`, `Make_Background`, `Make_Craft`, `Make_Invocation`, the Feat and Mastery factories) therefore wrapped every constant they wrote into a class namespace with a local helper, `Report_Of( value )`, which builds a Report returning the value. QST-0093.10 §2 proposed a value form upstream.

Julio's correction (Dialog 0027, 2026-10-05): *"The first one is supposed to be just a normal report."* Measured on 0.2.0a4: a plain value written on a Tag class is readable on the Tag and never lands on the Character. It already is a Report in effect. Only a **callable** stored as class data is different: TopKit turns a function or a Tag class into an Action on the Character. That is the one case the helper exists for.

## 🧾 Evidence

- Probe on 0.2.0a4 (Dialog 0027, Evidence §4): `NAME`, a tuple and a `@Report` are readable on the Tag and absent on the Character; a Tag class and a plain function stored as class data appear on the Character as Actions.
- The 69 sites, classified: 65 wrap plain strings, numbers, tuples, dicts or frozen records; 3 wrap something that may be a Tag or a function (`TrainingKit` `PATH`, `BackgroundKit` `ORIGIN_FEAT`, the generic `reports=` hook of `Make_Specialization`); 1 is the definition.

## 🎯 Desired outcome

Every plain constant is plain class data. `Report_Of` stays only for the three callable-bearing sites, and its docstring says exactly that. No Character and no sheet changes.

## 🛠️ What landed (2026-10-05, PR #102)

- 65 `Report_Of( value )` sites in 10 modules became plain class data; a multi-line string kept its parentheses; the inner calls (`tuple( … )`, `dict( … )`, `getattr( … )`) moved up one cascade level.
- `CharactersKit.Report_Of` keeps the three callable sites and explains when it is needed; its import is gone from the seven modules that no longer use it.
- **Gates, on Python 3.12 / TopKit 0.2.0a4 against the `main` baselines:** fingerprint 273 of 273 identical; sheet snapshot 343 of 343 read the same; `verify_equipment` output identical; replay exact; wide sweep 1164 of 1164; 12 of 14 kit self-tests pass, the same two pre-existing failures as on `main` (InvocationKit, FighterKit).

## 🧭 Notes for the Agora / implementer

- The factories' remaining namespace constants are the ones QST-0144.5 turns into Pin Records, Species-style; this station only stops wrapping them.
- Never store a function or a Tag class as plain class data on a Tag: it becomes an Action on every Agent.
